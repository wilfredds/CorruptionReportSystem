~/about

I'm a fourth-year BS Information Technology student at Lyceum of the Philippines University — Cavite, graduating in 2027. I like problems with a real person on the other end of them. AutoCare exists because a car care shop was tracking every job in a notebook and losing money to arithmetic. RallyReady exists because training badminton alone means nobody calls the corners for you. Bike Guide PH exists because beginner riders here have nowhere local to learn gearing.

I work across the stack — Next.js and Prisma on Postgres, React and TypeScript on Supabase, Flutter and Riverpod on Firebase — and I care about the parts that do not demo well: database constraints that make bad data impossible, security rules with assertions behind them, and CI that fails before a user does.

Every project here is in one repository with its own pipeline. Nothing on this page is a tutorial clone.

Next.js · Prisma · PostgreSQL

autocare/

A job-management system for a car care shop, built to replace a paper notebook. Seven-step wizard, one decision per screen; the running total is computed and can never be typed by hand. Prints a PDF receipt for every job. Bilingual (English / Filipino), role-based, with an activity log of every change.

  • Prisma

React · TypeScript · Supabase

rallyready/

Solo badminton training for a player with no coach and no partner. Every corner call is spoken aloud, so you never look at the screen. Split-step timing, audible fake calls, periodised programs, and a training-load model that tells you when to back off. Installable, and the whole trainer works offline.

Flutter · Riverpod · Firebase

cyclemind_ai/

An AI cycling coach and bike doctor in one Flutter app. Photograph a bike and a vision model returns a health report; the coach reads your rides and plans the next one. Clean Architecture throughout — every external dependency sits behind an interface, so the entire app runs on mocks with zero config and no API key ever ships in the binary.

  • Flutter
  • Dart
  • Riverpod
  • Firebase
  • Cloud Functions
  • Claude API

PWA · Vanilla JS · Firebase

bike-guide-app/

A cycling companion for Filipino beginner-to-intermediate riders: a gear simulator that explains which ring and cog to use on a climb, curated Philippine routes, GPS ride recording and a 30-day challenge. No framework, no bundler — sixteen pages of hand-written HTML, CSS and JavaScript that installs like an app and works offline.

  • Vanilla JS
  • Service Worker
  • Firebase
  • Geolocation API
  • Offline-first

Firestore · Security rules · Static

corruption-watch-ph/

A public reporting site: a citizen picks a department, describes what happened, and can file anonymously; an admin console reviews what comes in. The interesting work is invisible — the Firestore rules that let anyone write a report but nobody read someone else's, with 60 assertions run against the real emulator in CI.

  • Firebase
  • Firestore rules
  • Emulator tests
  • Vanilla JS
  • Anonymous submissions
